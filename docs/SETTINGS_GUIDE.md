# แนวทางตั้งค่าทั่วไป (General Settings)

เอกสารนี้แนะนำ **key ในตาราง `settings`** ที่ควรมี และการนำไปใช้ในแอป เพื่อให้แอดมินจัดการได้จากหน้า **ตั้งค่าทั่วไป** แทนการแก้ในโค้ด/constants

---

## สถานะปัจจุบัน

- ตาราง `settings`: คอลัมน์ `key`, `value` (JSON/object ได้), `updatedat`
- มี key **`shipping`** แล้ว – ใช้ในหน้าตั้งค่าการจัดส่ง และ Checkout (เปิด/ปิดรับเอง-จัดส่ง)
- **ข้อมูลร้าน (key `shop`)** – implement แล้ว: หน้าตั้งค่าทั่วไปมีฟอร์ม "ข้อมูลร้าน" บันทึกเป็น key `shop`; `shopSettingsService.getShopInfo()` ดึงจาก settings (มี cache 2 นาที) และ merge กับค่าเริ่มต้นจาก constants; ใบเสร็จ ใบกำกับ ใบปะหน้าพัสดุ ใช้ค่าจาก getShopInfo()

---

## ฟังก์ชัน/Key ที่แนะนำให้มี

### 1. ข้อมูลร้าน / ธุรกิจ (แนะนำ: key `shop` หรือ `business`)

| ค่าใน value (object) | ความหมาย | การใช้งานในแอป |
|----------------------|----------|-----------------|
| `name` | ชื่อร้าน/บริษัท | ใบเสร็จ, ใบกำกับภาษี, Header/Footer |
| `address` | ที่อยู่เต็ม | ใบกำกับภาษี, หน้าติดต่อ |
| `phone` | เบอร์โทรร้าน | ใบเสร็จ, หน้าติดต่อ, Footer |
| `taxId` | เลขประจำตัวผู้เสียภาษี (ร้าน) | ใบกำกับภาษี, ใบเสร็จ |
| `email` | อีเมลติดต่อ (ไม่บังคับ) | หน้าติดต่อ, Footer |
| `line` | Line ID / URL (ไม่บังคับ) | หน้าติดต่อ |

- **ประโยชน์:** แก้ชื่อร้าน/ที่อยู่/โทร/เลขภาษีได้จากแอดมิน ไม่ต้องแก้ constants แล้ว build ใหม่
- **การเชื่อม:** สร้าง service/hook อ่านจาก `settings` key `shop` แล้วให้ components (เช่น printService, TaxInvoice, Footer) ใช้ค่าจาก service แทน constants

---

### 2. อัตราภาษีมูลค่าเพิ่ม (key `vat`) ✅ ทำแล้ว

| ค่า | ความหมาย | การใช้งานในแอป |
|-----|----------|-----------------|
| ตัวเลข เช่น `7` | เปอร์เซ็นต์ VAT (เช่น 7%) | คำนวณ VAT ในใบกำกับภาษี, สรุปออเดอร์ |

- **สถานะ:** หน้าตั้งค่าทั่วไปมีบล็อก "อัตราภาษีมูลค่าเพิ่ม" บันทึกเป็น key `vat` (ตัวเลข 0–100). `shopSettingsService.getVatRate()` และ `calcVatFromTotal(total, rate)` ใช้ใน AdminOrders และ printService (ใบกำกับภาษี)
- **ประโยชน์:** เปลี่ยนอัตราภาษีได้จากตั้งค่าทั่วไป (เช่น 0% หรือ 7%)

---

### 3. โหมดบำรุงรักษา (key `maintenance`) ✅ ทำแล้ว

| ค่าใน value | ความหมาย | การใช้งานในแอป |
|-------------|----------|-----------------|
| `{ "enabled": true, "message": "กำลังปรับปรุงระบบ" }` | เปิดโหมดบำรุงรักษา | หน้า Login/Home แสดงข้อความและปิดการสั่งซื้อชั่วคราว |

- **สถานะ:** หน้าตั้งค่าทั่วไปมีบล็อก "โหมดบำรุงรักษา" (เปิด/ปิด + ข้อความ). แอดมินยังเข้าใช้งานได้; ผู้ใช้ทั่วไปและ path นอก login/register จะเห็นหน้า MaintenancePage
- **ประโยชน์:** ปิดระบบชั่วคราวโดยไม่ต้อง deploy ใหม่

---

### 4. ฟีเจอร์เปิด/ปิด (key `features`) ✅ ทำแล้ว

| ค่าใน value (object) | ความหมาย | การใช้งานในแอป |
|----------------------|----------|-----------------|
| `showCreditTopUp` | แสดงเมนูเติมเครดิตหรือไม่ | Header (ปุ่มเครดิต), Checkout (ช่องทางเครดิต/ลิงก์เติมเงิน), หน้า TopUp (redirect ถ้าปิด) |
| `allowCoupon` | เปิดใช้คูปองหรือไม่ | Checkout แสดง/ซ่อนช่องใส่โค้ดส่วนลด |
| `allowPromotion` | เปิดใช้โปรโมชั่นหรือไม่ | Checkout (คำนวณ/แสดงโปรโมชั่น) |

- **สถานะ:** หน้าตั้งค่าทั่วไปมีบล็อก "ฟีเจอร์เปิด/ปิด" บันทึกเป็น key `features`
- **ประโยชน์:** เปิด/ปิดฟีเจอร์จากแอดมินโดยไม่แก้โค้ด

---

### 5. การแจ้งเตือน / ขีดจำกัด (key `notifications`) ✅ ทำแล้ว

| ค่าใน value (object) | ความหมาย | การใช้งานในแอป |
|----------------------|----------|-----------------|
| `lowStockThreshold` | จำนวนขั้นต่ำที่ถือว่า "สต็อกต่ำ" | หน้าแจ้งเตือนสต็อก (StockAlert), badge ใน Sidebar (getLowStockCount) |
| `orderAlertEmail` | อีเมลรับแจ้งออเดอร์ใหม่ (ไม่บังคับ) | เก็บค่าไว้ อนาคตใช้ส่งอีเมลเมื่อมีออเดอร์ใหม่ |

- **สถานะ:** หน้าตั้งค่าทั่วไปมีบล็อก "การแจ้งเตือน / ขีดจำกัด" บันทึกเป็น key `notifications`
- **ประโยชน์:** ปรับขีดจำกัดสต็อกต่ำและช่องทางแจ้งเตือนจากตั้งค่า

---

### 6. ข้อความต้อนรับ / ท้ายหน้า ✅ ทำแล้ว

| Key | ความหมาย | การใช้งานในแอป |
|-----|----------|-----------------|
| `welcome_message` | ข้อความต้อนรับ (string) | หน้า Home แสดงด้านบนหลังล็อกอิน |
| `footer_text` | ข้อความท้ายหน้า (string) | Footer ด้านล่างเนื้อหาหน้า Home |

- **สถานะ:** หน้าตั้งค่าทั่วไปมีบล็อก "ข้อความต้อนรับ / ท้ายหน้า" บันทึก key `welcome_message`, `footer_text`

---

## Key ที่มีอยู่แล้ว

| Key | ความหมาย | หน้าที่เกี่ยวข้อง |
|-----|----------|-------------------|
| `shipping` | เปิด/ปิดรับเอง-จัดส่ง + อัตราค่าขนส่ง (จัดการละเอียดในหน้าตั้งค่าการจัดส่ง) | AdminShippingSettings, Checkout |

---

## ลำดับการ implement แนะนำ

1. **ข้อมูลร้าน (`shop`)** – ดึงจาก settings แทน constants ในใบเสร็จ/ใบกำกับ และ Footer (ผลลัพธ์เห็นชัดทันที)
2. **อัตราภาษี (`tax` / `vat`)** – อ่านจาก settings แล้วใช้ในคำนวณ VAT แทนค่า 7% แบบ hardcode
3. **โหมดบำรุงรักษา (`maintenance`)** – ตรวจที่ App/Login แล้วแสดงข้อความ + ปิดการสั่งซื้อ
4. **ฟีเจอร์เปิด/ปิด (`features`)** – ใช้ใน Checkout (คูปอง/โปรโมชั่น) และ Sidebar (เติมเครดิต)
5. **การแจ้งเตือน (`notifications`)** – ใช้กับขีดจำกัดสต็อกต่ำและ (ถ้าทำ) อีเมลแจ้งออเดอร์

---

## หมายเหตุ

- Key ใหม่สามารถ **เพิ่มจากหน้าตั้งค่าทั่วไป** ด้วยปุ่ม "เพิ่ม key" (value เป็น JSON ได้)
- Key ที่มี UI เฉพาะ (เช่น `shipping`) ควร **ลิงก์ไปหน้าการตั้งค่าที่เกี่ยวข้อง** แทนการแก้ value ตรงๆ ในตาราง เพื่อลดความผิดพลาดและ UX ที่ดีกว่า
