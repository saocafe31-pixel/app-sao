# คู่มือผู้ใช้ (User Guide)

เอกสารนี้สรุปการใช้งานแอป **SAO CAFE** สำหรับผู้ใช้ทั่วไป (ลูกค้า), **แฟรนไชส์** และ **แอดมิน**

---

## 1. บทบาทในระบบ

| บทบาท | การเข้าใช้งาน | เมนูหลัก |
|-------|----------------|----------|
| **ลูกค้า** | ล็อกอินด้วยอีเมล/รหัส หรือ Google | หน้าแรก, สินค้า, ตะกร้า, Checkout, ประวัติออเดอร์, โปรไฟล์, (เติมเครดิต ถ้าเปิดใช้) |
| **แฟรนไชส์** | เหมือนลูกค้า แต่มีสิทธิ์ดูสต็อกแฟรนไชส์, PO, ประวัติสต็อก | เหมือนลูกค้า + เมนูซ้าย: สต็อกแฟรนไชส์, ประวัติ, PO |
| **แอดมิน** | ล็อกอินแล้วเข้า Dashboard / เมนูซ้าย | Dashboard, จัดการออเดอร์, สต็อก, แจ้งเตือนสต็อก, PO, อนุมัติเครดิต, อนุมัติ UserType, แฟรนไชส์, ตั้งค่าการจัดส่ง, ตั้งค่าทั่วไป, จัดการซัพพลาย |

---

## 2. ลูกค้า (Customer)

### 2.1 ลงทะเบียน / เข้าสู่ระบบ
- **สมัครสมาชิก:** ไปที่หน้า Login → สมัครสมาชิก ใส่ชื่อ, อีเมล, รหัสผ่าน (หรือลงชื่อด้วย Google)
- **เข้าสู่ระบบ:** ใส่อีเมลและรหัสผ่าน หรือกด "ลงชื่อด้วย Google"

### 2.2 สั่งซื้อสินค้า
1. เลือกสินค้าจากหน้าแรก → เพิ่มลงตะกร้า
2. เปิดตะกร้า (ไอคอนรถเข็น) → ตรวจสอบรายการ
3. กด "สั่งซื้อ" → ไปหน้า Checkout
4. ใส่ที่อยู่, เลือกวิธีจัดส่ง (รับเอง/จัดส่ง), วิธีชำระเงิน (โอนเงิน หรือเครดิต ถ้าร้านเปิดใช้)
5. ถ้าร้านเปิดใช้คูปอง/โปรโมชั่น — ใส่โค้ดส่วนลดหรือรับโปรโมชั่นอัตโนมัติ
6. กดยืนยันสั่งซื้อ → แสดงใบเสร็จ/ใบกำกับ (ถ้ามี) และสถานะออเดอร์

### 2.3 เครดิต (ถ้าร้านเปิดใช้)
- **ดูยอด:** แถบด้านบนมีไอคอน wallet แสดงยอดเครดิต
- **เติมเงิน:** เมนู "เติมเครดิต" → เลือกจำนวนหรือใส่จำนวนเอง → ชำระตามที่แจ้ง → แอดมินอนุมัติแล้วเครดิตเข้า
- **ใช้เครดิต:** ใน Checkout เลือกชำระด้วย "เครดิต" (ได้เมื่อยอดเครดิตเพียงพอ)

### 2.4 ประวัติออเดอร์
- เมนู **ประวัติออเดอร์** — ดูรายการสั่งซื้อ, สถานะ, ใบเสร็จ/ใบกำกับ,  tracking (ถ้ามี)

### 2.5 โปรไฟล์
- เปลี่ยนชื่อ, รหัสผ่าน; ดู/แก้ข้อมูลส่วนตัว; ถ้าต้องการเป็นแฟรนไชส์ สามารถส่งคำขออนุมัติ UserType ได้จากหน้านี้

---

## 3. แฟรนไชส์ (Franchise)

- ใช้งานสั่งซื้อและประวัติเหมือนลูกค้า
- **เมนูเพิ่ม (ซ้าย):**
  - **สต็อกแฟรนไชส์** — ดู/จัดการสต็อกของร้านแฟรนไชส์ (โอนเข้า/ออกตามที่ระบบอนุญาต)
  - **ประวัติสต็อก** — ดูประวัติเข้า/ออก
  - **สั่งซื้อสินค้า (PO)** — สร้างใบสั่งซื้อส่งให้แอดมิน/ซัพพลาย

---

## 4. แอดมิน (Admin)

### 4.1 Dashboard
- สรุปภาพรวม: ออเดอร์ล่าสุด, สต็อกต่ำ, รายงานที่เข้าถึงได้จากเมนู

### 4.2 จัดการออเดอร์
- ดูรายการออเดอร์ทั้งหมด, กรองตามสถานะ (รอตรวจสอบ, ยืนยัน, ส่งแล้ว ฯลฯ)
- ตรวจสลิป/ยืนยันการชำระเงิน → อัปเดตสถานะ
- ใส่เลขติดตามพัสดุ (tracking), พิมพ์ใบเสร็จ/ใบกำกับ/ใบปะหน้าพัสดุ

### 4.3 จัดการสต็อก
- แก้ไขจำนวนสต็อกสินค้า, ดูประวัติเข้า/ออกสต็อก (ประวัติเข้าออกสต็อก)
- **แจ้งเตือนสต็อกต่ำ** — ดูรายการที่สต็อกต่ำกว่าเกณฑ์ (เกณฑ์ตั้งใน "ตั้งค่าทั่วไป" → การแจ้งเตือน)

### 4.4 สั่งซื้อสินค้า (PO)
- สร้าง/แก้ไข PO, เลือกซัพพลายเออร์และสินค้า, รับสินค้า (receive) → สต็อกกลางอัปเดตและมี stock_logs

### 4.5 อนุมัติเครดิต
- ดูรายการเติมเครดิตที่รออนุมัติ → อนุมัติหรือปฏิเสธ → ยอดเครดิตผู้ใช้อัปเดต

### 4.6 อนุมัติ UserType
- ดูคำขอเปลี่ยนเป็นแฟรนไชส์ (หรือประเภทอื่น) → อนุมัติ/ปฏิเสธ; ผู้ใช้จะได้รับแจ้งเตือน

### 4.7 รายชื่อแฟรนไชส์
- ดูรายชื่อผู้ใช้ที่เป็นแฟรนไชส์ (จาก user_approvals / users)

### 4.8 ตั้งค่าการจัดส่ง
- กำหนดอัตราค่าขนส่ง (ตามน้ำหนัก/ระยะ), เปิด/ปิดรับเอง-จัดส่ง (จาก settings key `shipping`)

### 4.9 ตั้งค่าทั่วไป
- **ข้อมูลร้าน:** ชื่อ, ที่อยู่, โทร, เลขภาษี, อีเมล, ลายเซ็น (ใช้ในใบเสร็จ/ใบกำกับ)
- **อัตราภาษี:** ตั้งค่า VAT (ใช้ในใบกำกับและคำนวณ)
- **โหมดบำรุงรักษา:** เปิดแล้วลูกค้าเห็นหน้า maintenance; แอดมินยังเข้าได้
- **ฟีเจอร์เปิด/ปิด:** แสดงเมนูเติมเครดิต, ใช้คูปอง, ใช้โปรโมชั่น
- **การแจ้งเตือน:** เกณฑ์สต็อกต่ำ, อีเมลแจ้งออเดอร์ใหม่ (ถ้ามีใช้)
- **ข้อความต้อนรับ / ท้ายหน้า:** ข้อความหน้าแรกและ footer
- **Key-Value อื่น:** จัดการ key ในตาราง settings เพิ่มเติม

รายละเอียด key ที่แนะนำ: **docs/SETTINGS_GUIDE.md**

### 4.10 จัดการซัพพลายเออร์
- เพิ่ม/แก้/ลบซัพพลายเออร์ (ใช้ใน PO และจัดการสต็อก)

### 4.11 คูปอง และ โปรโมชั่น
- **คูปอง:** สร้างโค้ดส่วนลด, กำหนดจำนวนครั้งใช้, ใช้ใน Checkout เมื่อร้านเปิดใช้คูปอง
- **โปรโมชั่น:** ตั้งโปรโมชั่น (เช่น ซื้อ X แถม Y), ใช้ใน Checkout เมื่อร้านเปิดใช้โปรโมชั่น

## 5. คำถามที่พบบ่อย (FAQ)

**Q: ลืมรหัสผ่านทำอย่างไร?**  
A: ตอนนี้ระบบใช้ custom login; ต้องมีฟังก์ชัน "ลืมรหัสผ่าน" (ส่งลิงก์ reset) ถ้า implement เพิ่ม หรือติดต่อแอดมิน

**Q: ออเดอร์อยู่ที่ไหน?**  
A: ลูกค้า/แฟรนไชส์ดูได้ที่ "ประวัติออเดอร์"; แอดมินดูที่ "จัดการออเดอร์"

**Q: เครดิตไม่เข้าหลังโอนเงิน?**  
A: แอดมินต้องไปที่ "อนุมัติเครดิต" แล้วกดอนุมัติรายการเติมเงินที่ตรงกับหลักฐานโอน

**Q: เปิดแอปแล้วเจอหน้า "กำลังบำรุงรักษา"?**  
A: แอดมินเปิดโหมดบำรุงรักษาไว้; ลูกค้าจะสั่งซื้อไม่ได้ชั่วคราว แอดมินยังเข้าได้ตามปกติ

**Q: อยากเป็นแฟรนไชส์?**  
A: จากโปรไฟล์ส่งคำขอเปลี่ยน UserType → แอดมินไปที่ "อนุมัติ UserType" เพื่ออนุมัติ
